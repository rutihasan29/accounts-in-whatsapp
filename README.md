# WhatsApp Audio Document Billing Bot 🤖

একটি Node.js ভিত্তিক WhatsApp Bot যা ডকুমেন্টে প্রাপ্ত অডিও ফাইলের সময়সীমা (Duration) মেপে স্বয়ংক্রিয়ভাবে বিল হিসাব করে এবং কাস্টমারের বকেয়া জমা রাখে।

---

## 📌 ফিচারসমূহ

1. **Audio Document Detection:** শুধু ডকুমেন্ট আকারে পাঠানো অডিও ফাইল প্রসেস করে (ভয়েস নোট ইগনোর করে)।
2. **Tiered Billing Calculator:**
   - 0:00 - 1:08 ➔ ৳ ৫০ টাকা
   - 1:09 - 1:19 ➔ ৳ ৭৫ টাকা
   - 1:20 - 2:08 ➔ ৳ ১০০ টাকা
   - *(এভাবে প্রতি ১ মিনিটে ৳ ৫০ টাকা এবং মাঝের বাফারে ৳ ২৫ টাকা বৃদ্ধি পায়)*
3. **বাংলা কমান্ড:**
   - `হিসাব`: কাস্টমারের বর্তমান মোট বকেয়া বিল দেখাবে।
   - `বিল ক্লিয়ার`: কাস্টমারের পূর্বের হিসাব রিসেট/জিরো (0) করে দেবে।
4. **Local Ledger (`bills.json`):** কাস্টমার অনুযায়ী লেনদেন সেভ হয়ে থাকে।
5. **Render & Koyeb Ready:** Dockerfile সহ প্রস্তুতকৃত।

---

## 🚀 লোকালি টেস্ট করার নিয়ম (Local Setup)

১. প্রথমে প্রয়োজনীয় প্যাকেজ ইনস্টল করুন:
```bash
npm install
```

২. টেস্টগুলো রান করে কোডের লজিক যাচাই করুন:
```bash
npm test
```

৩. বোট চালু করুন:
```bash
npm start
```
কন্সোলে একটি QR কোড আসবে, সেটি আপনার ফোনের WhatsApp দিয়ে স্ক্যান করুন।

## 🌐 Render.com-এ ২৪/৭ ফ্রিতে হোস্ট করার নিয়ম

১. এই প্রজেক্টের সমস্ত ফাইল আপনার **GitHub Repository**-তে Push করুন।
২. **Render.com Dashboard**-এ যান ➔ **New Web Service** সিলেক্ট করুন ➔ আপনার GitHub Repo কানেক্ট করুন।
৩. সেটআপের সময় **Environment: `Docker`** সিলেক্ট করুন।
৪. **Create Web Service**-এ ক্লিক করুন।
৫. সার্ভিস বিল্ড শেষ হলে Render-এর **Logs** ট্যাবে গিয়ে QR Code স্ক্যান করে নিন।
৬. Render-এর সার্ভিস লিঙ্কটি (যেমন `https://app-name.onrender.com`) **UptimeRobot.com**-এ ফ্রি HTTP Monitor হিসেবে যুক্ত করে দিন যাতে বোট কখনোই স্লিপ মোডে না যায়।
